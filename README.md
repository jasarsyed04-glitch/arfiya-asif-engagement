# Arfiya & Asif Ali — Interactive Engagement Invitation

## Pages
- `index.html` — envelope opening screen
- `invitation.html` — main invitation
- `details.html` — event details + countdown
- `style.css` — design
- `script.js` — interactions
- `assets/invitation.jpg` — supplied invitation artwork
- `server.js` — optional local Node.js server

## Run locally with Node.js
```bash
cd arfiya-asif-engagement
node server.js
```
Then open:
http://localhost:3000

## Publish with GitHub Pages
This is a static website, so Node.js is NOT required on GitHub Pages.

1. Create a GitHub repository, e.g. `arfiya-asif-invitation`.
2. Upload all files and the `assets` folder.
3. In GitHub: Settings → Pages.
4. Choose `Deploy from a branch`.
5. Select `main` and `/root`.
6. Save.
7. GitHub will give you the live invitation URL.

Keep `index.html` in the repository root.
